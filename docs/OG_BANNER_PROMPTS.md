## ✅ Banner Checklist

Before finalizing:
- [ ] Size is exactly 1200 x 630 pixels
- [ ] Text is readable at thumbnail size
- [ ] Logo is prominent
- [ ] Brand colors are consistent
- [ ] Call-to-action is clear
- [ ] No important text near edges (safe zone: 60px margin)
- [ ] Optimized file size (<500KB)
- [ ] Format: JPG or PNG
- [ ] Looks good on both light and dark backgrounds

## 📱 Implementation

Add to your `src/app/opengraph-image.tsx`:

```tsx
import { ImageResponse } from 'next/og'

export const runtime = 'edge'
export const alt = 'CloudInvoice - GST Invoicing Made Simple'
export const size = { width: 1200, height: 630 }
export const contentType = 'image/png'

export default async function Image() {
  return new ImageResponse(
    (
      <div
        style={{
          background: 'linear-gradient(135deg, #1e40af 0%, #7c3aed 100%)',
          width: '100%',
          height: '100%',
          display: 'flex',
          flexDirection: 'column',
          alignItems: 'center',
          justifyContent: 'center',
          fontFamily: 'system-ui',
        }}
      >
        <div style={{ 
          fontSize: 72, 
          fontWeight: 'bold', 
          color: 'white',
          marginBottom: 20,
        }}>
          CloudInvoice
        </div>
        <div style={{ 
          fontSize: 36, 
          color: '#e0e7ff',
          textAlign: 'center',
        }}>
          GST-Compliant Invoicing Made Simple
        </div>
        <div style={{ 
          fontSize: 24, 
          color: '#c7d2fe',
          marginTop: 40,
        }}>
          Free to Start • Trusted by 100+ Businesses
        </div>
      </div>
    ),
    {
      ...size,
    }
  )
}
```
